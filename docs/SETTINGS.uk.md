# Налаштування приводу Nice з Home Assistant

[Русский](SETTINGS.ru.md) · [Українська](SETTINGS.uk.md) · [English](SETTINGS.en.md)

Компонент `bus_t4` дозволяє читати й змінювати параметри блока керування Nice по шині BusT4 —
те саме, що робиться кнопками на блоці керування або через Nice O-View, але з Home Assistant.

## Як це працює

* Кожен параметр — окрема сутність ESPHome: `switch` (увімк/вимк), `number` (число), `select` (режим),
  `sensor` (лише читання), `button` (команда/калібрування).
* **Значення завжди береться з приводу.** Після старту ESP параметри зчитуються, потім перечитуються
  кожні `params_interval` (за замовчуванням 5 хвилин). Після запису параметр одразу перечитується — у HA
  показано те, що реально прийняв блок керування.
* Якщо змінити налаштування кнопками на самому приводі, HA побачить це при наступному читанні
  (або одразу — кнопкою «Refresh settings»).
* Якщо блок керування не підтримує параметр, він відповідає помилкою, і сутність лишається без значення.
  Непідтримувані параметри краще не додавати в YAML.
* Якщо значення поза допустимим діапазоном блока, привод його відхилить, і сутність покаже попереднє значення.

## Підключення

```yaml
external_components:
  - source: github://srepenko/Nice_BusT4@main
    refresh: 0s

cover:
  - platform: bus_t4
    id: nice_cover
    name: "Nice Cover"
    device_class: gate
    tx_pin: 21
    rx_pin: 20
    params_interval: 5min      # як часто перечитувати налаштування (необов'язково)
```

У всіх сутностях нижче `platform: bus_t4` і (необов'язково) `bus_t4_id: nice_cover`, якщо cover не один.

> **Імена.** В ESPHome 2026+ object_id будується з ASCII, тому кириличні імена однакової довжини
> конфліктують. Давайте імена латиницею, а українські задавайте в Home Assistant
> (Налаштування → Сутності → ім'я).

## Функції (`switch`)

| `type` | Регістр | Що робить |
|---|---|---|
| `auto_close` | 0x80 | **Автозакриття** (L1). Після повного відкриття ворота самі закриються через «час паузи». |
| `photo_close` | 0x84 | **Закрити після фото** (L2). Якщо проїхали крізь фотоелементи, ворота закриються через `photo_close_time`, не чекаючи всієї паузи. |
| `always_close` | 0x88 | **Завжди закривати** (L3). Якщо після зникнення живлення ворота відчинені, блок закриє їх через `always_close_time`. |
| `standby` | 0x8C | **Режим очікування / енергозбереження** (L4). Через `standby_time` бездіяльності блок вимикає частину споживачів (див. `standby_mode`). |
| `preflash` | 0x94 | **Попереднє мерехтіння**. Сигнальна лампа блимає перед початком руху (час — `preflash_open_time` / `preflash_close_time`). |
| `operator_block` | 0x9A | **Блокування приводу**. Привод не виконує команди керування (обслуговування, прибирання). |
| `key_lock` | 0x9C | **Блокування кнопок** на блоці керування (захист від випадкової зміни налаштувань). |
| `custom` + `register` | будь-який | Будь-який параметр-прапорець 0/1 з протоколу. |

## Числові параметри (`number`)

| `type` | Регістр | Одиниці | Опис |
|---|---|---|---|
| `pause_time` | 0x81 | с | **Час паузи** — скільки ворота стоять відчиненими перед автозакриттям. |
| `photo_close_time` | 0x85 | с | Очікування перед закриттям після спрацювання фотоелементів. |
| `always_close_time` | 0x89 | с | Через скільки закрити після ввімкнення живлення (функція «Завжди закривати»). |
| `standby_time` | 0x8D | с | Через скільки бездіяльності ввімкнеться режим очікування. |
| `preflash_open_time` | 0x95 | с | Мерехтіння перед відкриванням. |
| `preflash_close_time` | 0x99 | с | Мерехтіння перед закриванням. |
| `lamp_time` | 0x5B | с | Час роботи лампи підсвітки (courtesy light) після маневру. |
| `lock_time` | 0x5A | с | Тривалість імпульсу електрозамка. |
| `suction_cup_time` | 0x5C | с | Час роботи електромагнітної присоски. |
| `speed_open` / `speed_close` | 0x42 / 0x43 | рівень | Швидкість відкривання / закривання. |
| `speed_slow_open` / `speed_slow_close` | 0x45 / 0x46 | рівень | Швидкість на ділянці уповільнення біля крайніх положень. |
| `force_open` / `force_close` | 0x4A / 0x4B | рівень | Зусилля (поріг чутливості до перешкоди). Менше — чутливіше й безпечніше, більше — сильніше штовхає (вітер, тугі петлі). |
| `leaf_delay_open` / `leaf_delay_close` | 0x28 / 0x29 | одиниці блока | Зсув стулок у двостулкових воріт: друга стулка рушає пізніше, щоб стулки не зіткнулися. |
| `reverse_time` | 0x31 | одиниці блока | Тривалість короткого реверсу (відкату) при виявленні перешкоди. |
| `custom` | будь-який | — | Будь-який числовий параметр: `register`, `bytes` (1–4), `multiplier`, `min_value`, `max_value`, `step`. |

**Рівні швидкості й зусилля** — це шкала конкретного блока керування. Діапазон у компоненті 1–8; якщо
блок підтримує менше рівнів, зайві значення він відхилить. На Nice Walky (WLA1) з заводу: швидкість 3,
уповільнення 2, зусилля 2.

**Безпека.** Не завищуйте зусилля без потреби: це поріг, за якого привод вважає, що вперся в перешкоду.
Після зміни швидкості/зусилля перевірте, що ворота зупиняються й від'їжджають, якщо притримати стулку рукою.

## Режими (`select`)

| `type` | Регістр | Варіанти |
|---|---|---|
| `standby_mode` | 0x8E | `Safety` — вимикати пристрої безпеки; `BlueBus` — вимикати шину BlueBus; `All` — усе. |
| `custom` | будь-який | Свій список `options: {"Підпис": значення}`. |

## Датчики (`sensor`, лише читання)

| `type` | Регістр | Опис |
|---|---|---|
| `maneuvers_count` | 0xB2 | Лічильник маневрів від останнього обслуговування. |
| `maintenance_threshold` | 0xB1 | Поріг обслуговування (у маневрах). Коли лічильник дійде до порогу, блок сигналізує про потребу ТО. |
| `custom` | будь-який | `register`, `bytes`, `multiplier`. |

## Кнопки (`button`)

| `type` | Що робить |
|---|---|
| `learn_positions` | **Навчання положень / розпізнавання довжини стулки.** Ворота виконують повний цикл, блок запам'ятовує крайні положення. Робиться після монтажу, регулювання упорів, заміни приводу. ⚠️ Ворота почнуть рухатися — переконайтеся, що в проїзді нікого немає. |
| `learn_bluebus` | **Розпізнавання пристроїв BlueBus** (фотоелементи, кнопкові пости тощо). Потрібно після додавання/заміни пристроїв на шині. |
| `cancel_maintenance` | **Скидання обслуговування** — обнуляє лічильник до ТО. Робіть після сервісу приводу. |
| `refresh` | Перечитати всі налаштування з приводу зараз. |
| `step_by_step`, `open`, `close`, `stop`, `partial_open` | Команди керування (покроково, відкрити, закрити, стоп, часткове відкриття/хвіртка). |

## Перевірено

Nice **Walky** (блок WLA1, розпашні ворота, 2 стулки): підтримуються 52 параметри. Не підтримуються:
часткові відкривання 1–3, позиції за енкодером, уповільнення увімк/вимк, плавний пуск, входи IN2–IN4.

Для інших блоків (ROBUS, SPIN, MC824H, DPRO924…) набір параметрів може відрізнятися. Щоб дізнатися, що
підтримує ваш блок, надішліть GET-запити через службу `send_inf_command` (`type_command: 99`)
і подивіться відповіді в лозі: помилка `FD`/`F9` — параметр не підтримується.
