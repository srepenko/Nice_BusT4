# Настройки привода Nice из Home Assistant

[Русский](SETTINGS.ru.md) · [Українська](SETTINGS.uk.md) · [English](SETTINGS.en.md)

Компонент `bus_t4` позволяет читать и менять параметры блока управления Nice по шине BusT4 —
то же, что делается кнопками на блоке управления или через Nice O-View, но из Home Assistant.

## Как это работает

* Каждый параметр — отдельная сущность ESPHome: `switch` (вкл/выкл), `number` (число), `select` (режим),
  `sensor` (только чтение), `button` (команда/калибровка).
* **Значение всегда берётся из привода.** После старта ESP параметры читаются, затем перечитываются
  каждые `params_interval` (по умолчанию 5 минут). После записи параметр сразу перечитывается — в HA
  отображается то, что реально принял блок управления.
* Если поменять настройку кнопками на самом приводе, HA увидит это при следующем чтении
  (или сразу — кнопкой «Refresh settings»).
* Если блок управления не поддерживает параметр, он отвечает ошибкой, и сущность остаётся без значения.
  Неподдерживаемые параметры лучше не добавлять в YAML.
* Если значение вне допустимого диапазона блока, привод его отклонит, и сущность покажет прежнее значение.

## Подключение

```yaml
external_components:
  - source: github://srepenko/Nice_BusT4@main
    refresh: 0s

cover:
  - platform: bus_t4
    id: nice_cover
    name: "Nice Cover"
    device_class: gate
    tx_pin: 21
    rx_pin: 20
    params_interval: 5min      # как часто перечитывать настройки (необязательно)
```

Во всех сущностях ниже `platform: bus_t4` и (необязательно) `bus_t4_id: nice_cover`, если cover не один.

> **Имена.** В ESPHome 2026+ object_id строится из ASCII, поэтому кириллические имена одинаковой длины
> конфликтуют. Давайте имена латиницей, а русские/украинские задавайте в Home Assistant
> (Настройки → Объекты → имя).

## Функции (`switch`)

| `type` | Регистр | Что делает |
|---|---|---|
| `auto_close` | 0x80 | **Автозакрытие** (L1). После полного открытия ворота сами закроются через «время паузы». |
| `photo_close` | 0x84 | **Закрыть после фото** (L2). Если проехали через фотоэлементы, ворота закроются через `photo_close_time`, не дожидаясь полной паузы. |
| `always_close` | 0x88 | **Всегда закрывать** (L3). Если после пропадания питания ворота открыты, блок закроет их через `always_close_time`. |
| `standby` | 0x8C | **Режим ожидания / энергосбережение** (L4). Через `standby_time` бездействия блок отключает часть потребителей (см. `standby_mode`). |
| `preflash` | 0x94 | **Предмерцание**. Сигнальная лампа мигает перед началом движения (время — `preflash_open_time` / `preflash_close_time`). |
| `operator_block` | 0x9A | **Блокировка привода**. Привод не выполняет команды управления (обслуживание, уборка). |
| `key_lock` | 0x9C | **Блокировка кнопок** на блоке управления (защита от случайного изменения настроек). |
| `custom` + `register` | любой | Любой параметр-флаг 0/1 из протокола. |

## Числовые параметры (`number`)

| `type` | Регистр | Единицы | Описание |
|---|---|---|---|
| `pause_time` | 0x81 | с | **Время паузы** — сколько ворота стоят открытыми перед автозакрытием. |
| `photo_close_time` | 0x85 | с | Ожидание перед закрытием после срабатывания фотоэлементов. |
| `always_close_time` | 0x89 | с | Через сколько закрыть после включения питания (функция «Всегда закрывать»). |
| `standby_time` | 0x8D | с | Через сколько бездействия включится режим ожидания. |
| `preflash_open_time` | 0x95 | с | Предмерцание перед открыванием. |
| `preflash_close_time` | 0x99 | с | Предмерцание перед закрыванием. |
| `lamp_time` | 0x5B | с | Время работы лампы подсветки (courtesy light) после манёвра. |
| `lock_time` | 0x5A | с | Время импульса электрозамка. |
| `suction_cup_time` | 0x5C | с | Время работы электромагнитной присоски. |
| `speed_open` / `speed_close` | 0x42 / 0x43 | уровень | Скорость открывания / закрывания. |
| `speed_slow_open` / `speed_slow_close` | 0x45 / 0x46 | уровень | Скорость на участке замедления у крайних положений. |
| `force_open` / `force_close` | 0x4A / 0x4B | уровень | Усилие (порог чувствительности к препятствию). Меньше — чувствительнее и безопаснее, больше — сильнее толкает (ветер, тугие петли). |
| `leaf_delay_open` / `leaf_delay_close` | 0x28 / 0x29 | единицы блока | Сдвиг створок у двустворчатых ворот: вторая створка начинает движение позже, чтобы створки не столкнулись. |
| `reverse_time` | 0x31 | единицы блока | Длительность короткого реверса (отката) при обнаружении препятствия. |
| `custom` | любой | — | Любой числовой параметр: `register`, `bytes` (1–4), `multiplier`, `min_value`, `max_value`, `step`. |

**Уровни скорости и усилия** — это шкала конкретного блока управления. Диапазон в компоненте 1–8; если
блок поддерживает меньше уровней, лишние значения он отклонит. На Nice Walky (WLA1) с завода: скорость 3,
замедление 2, усилие 2.

**Безопасность.** Не завышайте усилие без необходимости: это порог, при котором привод считает, что
упёрся в препятствие. После изменения скорости/усилия проверьте, что ворота останавливаются и отъезжают,
если придержать створку рукой.

## Режимы (`select`)

| `type` | Регистр | Варианты |
|---|---|---|
| `standby_mode` | 0x8E | `Safety` — отключать устройства безопасности; `BlueBus` — отключать шину BlueBus; `All` — всё. |
| `custom` | любой | Свой список `options: {"Подпись": значение}`. |

## Датчики (`sensor`, только чтение)

| `type` | Регистр | Описание |
|---|---|---|
| `maneuvers_count` | 0xB2 | Счётчик манёвров с последнего обслуживания. |
| `maintenance_threshold` | 0xB1 | Порог обслуживания (в манёврах). Когда счётчик дойдёт до порога, блок сигнализирует о необходимости ТО. |
| `custom` | любой | `register`, `bytes`, `multiplier`. |

## Кнопки (`button`)

| `type` | Что делает |
|---|---|
| `learn_positions` | **Обучение положений / распознавание длины створки.** Ворота выполняют полный цикл, блок запоминает крайние положения. Делается после монтажа, регулировки упоров, замены привода. ⚠️ Ворота начнут двигаться — убедитесь, что в проезде никого нет. |
| `learn_bluebus` | **Распознавание устройств BlueBus** (фотоэлементы, кнопочные посты и т.п.). Нужно после добавления/замены устройств на шине. |
| `cancel_maintenance` | **Сброс обслуживания** — обнуляет счётчик до ТО. Делайте после сервиса привода. |
| `refresh` | Перечитать все настройки из привода сейчас. |
| `step_by_step`, `open`, `close`, `stop`, `partial_open` | Команды управления (пошагово, открыть, закрыть, стоп, частичное открытие/калитка). |

## Проверено

Nice **Walky** (блок WLA1, распашные ворота, 2 створки): поддерживаются 52 параметра. Не поддерживаются:
частичные открывания 1–3, позиции по энкодеру, замедление вкл/выкл, плавный пуск, входы IN2–IN4.

Для других блоков (ROBUS, SPIN, MC824H, DPRO924…) набор параметров может отличаться. Чтобы узнать, что
поддерживает ваш блок, отправьте GET-запросы через службу `send_inf_command`
(`type_command: 99`) и посмотрите ответы в логе: ошибка `FD`/`F9` — параметр не поддерживается.
